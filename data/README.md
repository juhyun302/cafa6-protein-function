# 로컬 데이터

- raw/: 원본 FASTA·annotation·구조·GO 매핑·다른 모델 예측
- processed/: accession 목록 등 재생성 가능한 중간 데이터
- ../artifacts/: 검색 결과·예측·로그

대형 ID 목록 사본과 실행 로그는 저장소에서 제외했습니다. 원천 FASTA에서 python scripts/cafa.py extract-accessions 명령으로 재생성하세요.

[데이터 형식과 출처 설명](../docs/data-and-glossary.md) · [전체 실행 순서](../docs/setup.md)

원본 대회 데이터와 GO 매핑·임베딩은 이 저장소에 포함되어 있지 않습니다. 작은 합성 입력은 ../examples/에 있습니다.
